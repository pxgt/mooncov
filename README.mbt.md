# mooncov

`mooncov` is a pure MoonBit coverage-report toolkit. It gives CI pipelines and
developer tools one data model for LCOV and Coveralls JSON, then provides
deterministic merging, path filtering, threshold gates, diff coverage, and
human- or machine-readable reports.

The project is an original MoonBit implementation. It follows the public LCOV
tracefile conventions and the Coveralls JSON schema for interoperability; no
source code has been copied from either ecosystem.

> The public API and examples are under active construction for version 0.1.0.
